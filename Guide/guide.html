OMNIPKG

> one script. any distro. any package manager.

Stop looking up install commands every time you set up a machine. OmniPKG detects your package manager, updates your system, installs your list, and cleans up — across 22 different package managers, from apt to winget.

View on GitHub Install Guide

Features

  • Unified config file — package lists and per-manager commands in one packages.json
  • 22 package managers supported out of the box
  • One-time sudo prompt instead of asking at every step
  • Live progress feedback while it works
  • Automatic cleanup after installation

Install in 4 steps

  1. Clone the repository 
    git clone https://github.com/CAgent47/OmniPKG.git
cd OmniPKG
  2. Make it executable 
    chmod +x omnipkg.sh
  3. Run it (you'll be asked for your sudo password once) 
    ./omnipkg.sh
  4. Customize your package list anytime in core/packages.json

Security note

OmniPKG asks for your sudo password once and keeps the session alive for the duration of the script, instead of prompting repeatedly. This is a convenience trade-off meant for machines you personally control — always read a script before running it with elevated privileges.

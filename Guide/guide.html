OMNIPKG

> one script. any distro. any package manager.

Stop looking up install commands every time you set up a machine. OmniPKG detects your package manager, updates your system, installs your list, and cleans up — across 22 different package managers, from apt to winget.

What's inside the box

  • ☑

    Unified config file

    Package lists and per-manager commands live in one packages.json — no juggling separate files.

  • ☑

    22 package managers

    apt, dnf, pacman, zypper, apk, brew, winget, choco, nix, and more — out of the box.

  • ☑

    One-time sudo prompt

    Enter your password once — the session stays alive for the rest of the run.

  • ☑

    Live progress feedback

    A spinner and progress indicator so you always know something's happening.

  • ☑

    Redesigned terminal UI

    Boxed banner, color-coded sections, readable status messages at every step.

  • ☑

    Automatic cleanup

    Orphaned packages and caches removed automatically per package manager.

Handling Instructions

Install in 4 steps

  1. Clone the repository

    Pull the project down to your machine.

    git clone https://github.com/CAgent47/OmniPKG.git
cd OmniPKG

  2. Make it executable

    Grant run permission to the main script.

    chmod +x omnipkg.sh

  3. Run it

    Enter your sudo password once when asked.

    ./omnipkg.sh

  4. Customize your package list

    Edit the install line for your package manager in the config, then re-run anytime.

    core/packages.json
⚠ Fragile — Read First

OmniPKG asks for your sudo password once and keeps the session alive for the duration of the script, instead of prompting repeatedly. This is a convenience trade-off meant for machines you personally control — always read a script before running it with elevated privileges.
